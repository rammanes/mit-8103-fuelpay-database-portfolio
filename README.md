# FuelPay Network – MIT 8103 Advanced Database Systems Portfolio

**Course:** MIT 8103 – Advanced Database Systems (2026/2027, First Semester CA)
**Student:** Abdulrahman Danjuma

## Case study

FuelPay Network is a simulated fintech platform that provides cashless fuel payment and fuel expenditure management for corporate organisations, fleet operators and individual motorists across a network of participating filling stations.

**Users:** individual customers, corporate administrators, filling station operators, finance officers, system administrators and auditors.

**Main data:** customers, organisations, employees, vehicles, accounts, NFC payment instruments, fuel stations, fuel products, purchases, financial transactions, account ledger entries, fuel allowances and audit records.

**Key operations:** account funding, fuel purchases, allowance enforcement, duplicate-payment prevention, reversals, concurrent payments across stations, and expenditure reporting.
